# 我的计算器喵~ · 高中数学化学计算器

> **我的计算器喵~** 是一款面向中国大陆高中生（以及所有喜欢精确答案的人）的数学 / 化学计算与公式输入工具。
> 纯静态前端，零后端、零追踪、完全离线可用，可一键部署至 GitHub Pages。

## 🐾 产品介绍

高中刷题时最烦什么？**算对了却不给分**——因为答案是 `√3/2` 你却按成了 `0.866`；
**符号打不出来**——α β θ ∑ ∫ ⇌ 到处搜；**化学配平配到怀疑人生**。

「我的计算器喵~」就是来解决这些的：

- **精确值优先**：`1/2+1/3` 直接给你 `5/6`，小数只是顺便一看。特殊角三角值给根式（sin60° = √3/2），二次方程给精确根和判别式说明，绝不拿近似数糊弄你。
- **错误说人话**：`(1+2` 会告诉你「缺少右括号」并用箭头指出位置，永远不会蹦出冷冰冰的 `undefined` 或 `NaN`。
- **化学只建议不强改**：输入方程式，App 算出最小整数系数给你预览，你确认才应用，随时一键撤销——工具不该替你做主。
- **复制就能用**：结果、公式、化学式都能复制成带上下标的纯文本（H₂O、SO₄²⁻、x²+2x），直接粘进微信、QQ、Word 或者发给 AI 都不乱码。
- **手机是第一公民**：单指拖动、双指缩放的函数图像；≥16px 输入框防 iOS 抽风放大；320px 小屏到 1440px 大屏都排得整整齐齐。
- **数据是你的**：所有记录存在本机浏览器，不上传任何服务器；换设备前导出一个 JSON 备份即可完整搬家。

一句话：**它不装聪明，只做靠谱。**

**产品第一原则：正确性 > 输入体验 > 移动端体验 > 易用性 > 可理解性 > 性能 > 美观 > 动画。**

## 功能

### 🧮 数学计算器
- 四则、分数、根号、指数、对数、三角（角度/弧度可切）、阶乘、百分号、复数
- **精确值优先**：`1/2+1/3` 主显示小数，精确形式 `5/6` 一键复制；特殊角三角值给根式（sin60°=√3/2）
- 方程求解：一次/二次给出精确根（含判别式说明与复根），高次数值解并标注「近似」；线性方程组高斯消元
- 中文错误信息 + 位置箭头定位，永不出现裸 `undefined/NaN`
- 简单/专业双模式键盘、会话历史、★ 收藏、Undo/Redo

### ✏️ 公式编辑器
- LaTeX 源码 + KaTeX 实时大预览
- 结构化插入（分数/根号/上下标/求和/积分/极限/矩阵），选中内容自动填入模板
- 可预测快捷键：`/` `^` `_` 包裹选中内容；`sqrt␣` `sum␣` `alpha␣` 等整词+空格才展开
- 复制 LaTeX / 复制为纯文本（H₂O 式上下标字符，可直接粘进微信/QQ/Word/AI）
- 高中公式库：数列/三角/向量/导数/圆锥曲线/直线圆等 8 类约 40 条，点击载入修改

### 🔣 特殊符号面板
105+ 符号带中文名搜索；**按使用频率自动排序** + 收藏；点击即复制。

### 🧪 化学
- 化学式编辑：下标自动渲染、括号分组、结晶水 `CuSO4·5H2O`、离子智能判读（`Cu2+`→Cu²⁺、`SO42-`→SO₄²⁻、显式 `^2-` 永远优先）、状态标注 (s)/(l)/(g)/(aq)
- 相对分子质量 Mr 与元素质量分数表
- **配平建议**：有理数高斯消元求最小整数系数，含电荷守恒校验；只建议不强制，应用前预览、应用后可撤销
- 计算器套件：物质的量/粒子数/气体体积、浓度 c=n/V、质量分数、稀释四项互求、pH ↔ c(H⁺) ↔ c(OH⁻)
- 元素周期表数据内置（118 位，中文名 + 相对原子质量）

### 📈 函数绘图
- 最多 6 条函数同绘，Canvas 高清渲染
- 单指拖动平移、双指捏合缩放（锚点不动）、滚轮缩放、双击复位
- 触摸坐标读数：x 与各函数 y 值实时显示
- 弧度制；定义域外自动断笔，tan 渐近线跳变检测

### 💾 数据（全部存本机浏览器）
- 导出完整备份 JSON / 导入合并或替换，逐字段清洗校验
- 版本迁移框架：旧备份自动升级
- 无网络上传、无统计埋点

### 🎨 主题
- 内置 9 款官方主题：🧊毛玻璃效果（默认） 🤍极简白 🌌深紫 🖤OLED黑 🌸二次元 🌊蓝色 🌿清新 📚学习工具 💻Terminal
- **第三方主题**：导入 `.json` 或含 `theme.json` 的 `.zip`
- 安全模型：令牌白名单 + 值字符集校验 + CSS 全程程序拼装——**任何脚本、链接、未知字段都会被丢弃，零代码执行**
- 全站动画开关（遵循系统「减少动态效果」）、字号四档缩放

### ♿ 无障碍 & 移动端
- 键盘全流程可用（Enter 计算、Ctrl+Z 撤销、Esc 关闭引导）、ARIA 标注完整
- 320–1440px 自适应；输入框 ≥16px 防 iOS 聚焦缩放；safe-area 适配
- 首次启动新手引导（4 步，可跳过，进度保存）

## 开发

```bash
npm install         # 安装依赖
npm run dev         # 本地开发服务器
npm test            # Vitest 单元测试（引擎 + UI 冒烟）
npm run typecheck   # TypeScript 严格模式检查
npm run build       # 类型检查 + 生产构建（输出 dist/）
npm run preview     # 本地预览生产构建
```

技术栈：Vite · React · TypeScript(strict) · zustand · KaTeX（懒加载）· JSZip（仅导入 ZIP 主题时下载）。
数学引擎（BigInt 有理数 → 根式 → 浮点 → 复数四级提升）与化学引擎（解析/配平/热力学常量）均为自研模块，不引入重型符号计算依赖，错误信息可控、结果可审计。

代码分割：主包 ≈83 KB gzip；KaTeX、JSZip 与各视图均按需加载。

### 目录速览

```
src/
├─ engine/math/      数学引擎（值系统/解析/求值/求解/格式化/LaTeX）
├─ engine/chem/      化学引擎（解析/渲染/方程配平/计算器）
├─ engine/plot/      绘图（数值编译/视口变换）
├─ engine/text/      LaTeX→Unicode 转换
├─ data/             元素周期表/符号库/公式库/参考数据
├─ store/            zustand 存储（设置/历史/符号/备份桥接）
├─ theme/            官方主题注册 + 第三方主题安全管线
├─ components/       UI 组件（计算器/化学/公式/符号/绘图…）
├─ views/            七大视图页
└─ styles/           设计令牌与样式
```

### 第三方主题格式

```json
{
  "name": "我的主题",
  "appearance": "dark",
  "tokens": {
    "--bg": "#0b0b10",
    "--panel": "#15151d",
    "--border": "#2a2a36",
    "--text": "#eeeeee",
    "--accent": "#7aa2f7"
  }
}
```

支持全部语义令牌见 `src/theme/custom.ts` 的白名单；ZIP 导入需把上述内容命名为 `theme.json` 放在压缩包内。

## 部署（GitHub Pages）

- 构建使用相对路径 `base: './'`，产物可部署在任意子路径。
- 推送到 `main` 分支后由 `.github/workflows/deploy.yml` 自动 测试 → 构建 → 发布到 GitHub Pages。
- 首次启用：仓库 Settings → Pages → Source 选择 **GitHub Actions**。
