# 我的计算器喵~

面向高中生的数学 / 化学计算与公式输入工具。纯静态前端，无后端、无追踪、离线可用，可一键部署到 GitHub Pages。

## 它解决什么

- **答案要精确**：`1/2+1/3` 给 `5/6`，sin60° 给 `√3/2`，二次方程给精确根和判别式说明。小数只是附带，绝不拿近似值糊弄。
- **错误说人话**：缺括号就指出缺在哪里，不会蹦 `undefined`、`NaN`。
- **化学只建议不强改**：配平算出最小整数系数供预览，你确认才应用，随时撤销。
- **复制即用**：结果、公式、化学式可复制为带上标的纯文本（H₂O、SO₄²⁻、x²+2x），粘进 Word / 微信 / AI 都不乱码。
- **数据在本机**：全部记录存浏览器，不上传、无统计埋点；换设备导出 JSON 备份即可搬家。

产品原则：正确性 > 输入体验 > 移动端体验 > 易用性 > 可理解性 > 性能 > 外观。

## 功能一览

| 模块 | 说明 |
|---|---|
| 数学计算器 | 四则 / 分数 / 根式 / 指数 / 对数 / 三角（度量可切）/ 阶乘 / 复数；一次二次方程与线性方程组求解；简单 / 专业双模式键盘；历史、收藏、撤销重做 |
| 公式编辑器 | LaTeX 实时预览；分数、根号、求和、积分、矩阵等结构化插入；高中公式库 8 类约 40 条；复制 LaTeX 或纯文本 |
| 符号面板 | 105+ 符号带中文名搜索，按使用频率自动排序 + 收藏，点击即复制 |
| 化学 | 化学式渲染、离子智能判读、结晶水与状态标注；相对分子质量与质量分数；配平建议（有理数消元 + 电荷守恒校验）；物质的量 / 浓度 / 稀释 / pH 计算；118 元素内置 |
| 函数绘图 | 最多 6 条同绘；触屏拖动缩放、坐标读数；定义域外断笔、tan 渐近线处理 |
| 主题 | 内置 9 款（毛玻璃默认）；第三方主题导入 JSON / ZIP，令牌白名单校验，零代码执行 |
| 无障碍与移动端 | 键盘全流程可用、ARIA 完整；320–1440px 自适应；输入框 ≥16px 防 iOS 聚焦缩放；遵从系统「减少动态效果」 |

## 开发

```bash
npm install         # 安装依赖
npm run dev         # 本地开发服务器
npm test            # Vitest 单元测试（引擎 + UI 冒烟）
npm run typecheck   # TypeScript 严格模式检查
npm run build       # 类型检查 + 生产构建（输出 dist/）
npm run preview     # 本地预览生产构建
```

技术栈：Vite · React · TypeScript(strict) · zustand · KaTeX（懒加载）· JSZip（仅导入 ZIP 主题时下载）。
数学引擎（BigInt 有理数 → 根式 → 浮点 → 复数四级提升）与化学引擎均为自研，不引入重型符号计算依赖。主包 ≈83 KB gzip，各视图按需加载。

### 目录速览

```
src/
├─ engine/math/      数学引擎（值系统/解析/求值/求解/格式化/LaTeX）
├─ engine/chem/      化学引擎（解析/渲染/方程配平/计算器）
├─ engine/plot/      绘图（数值编译/视口变换）
├─ engine/text/      LaTeX→Unicode 转换
├─ data/             元素周期表/符号库/公式库/参考数据
├─ store/            zustand 存储（设置/历史/符号/备份桥接）
├─ theme/            官方主题注册 + 第三方主题安全管线
├─ components/       UI 组件（计算器/化学/公式/符号/绘图…）
├─ views/            七大视图页
└─ styles/           设计令牌与样式
```

### 第三方主题格式

```json
{
  "name": "我的主题",
  "appearance": "dark",
  "tokens": {
    "--bg": "#0b0b10",
    "--panel": "#15151d",
    "--border": "#2a2a36",
    "--text": "#eeeeee",
    "--accent": "#7aa2f7"
  }
}
```

支持的全部语义令牌见 `src/theme/custom.ts` 白名单；ZIP 导入需把上述内容命名为 `theme.json` 放在压缩包内。

## 部署（GitHub Pages）

- 构建使用相对路径 `base: './'`，产物可部署在任意子路径。
- 推送到 `main` 后由 `.github/workflows/deploy.yml` 自动测试 → 构建 → 发布。
- 首次启用：Settings → Pages → Source 选择 **GitHub Actions**。
